# Build Project Workflow

This workflow details how to install dependencies, run TypeScript type checking, and compile the production build for the WishStream (BddayList) Next.js app.

## Prerequisites

- Node.js >= v20 installed (`node --version`)

## Steps

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **TypeScript Typecheck**
   ```bash
   npm run typecheck
   ```

3. **Build Web Application**
   ```bash
   npm run build
   ```
