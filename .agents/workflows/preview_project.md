# Preview Project Workflow

This workflow details how to start the development server and preview the WishStream (BddayList) app locally.

## Steps

1. **Start Development Server**
   ```bash
   npm run dev
   ```
   *The server runs locally on [http://localhost:9002](http://localhost:9002).*

2. **Verify Application**
   - Open [http://localhost:9002](http://localhost:9002) in your browser or DevTools.
   - Confirm the landing page and stream dashboard load cleanly without errors.
